# ComEx Wiki — Business Context

**ComEx is the Sales Forces team in charge of all sales operations.** This wiki is the only source of truth for what the team does, which apps it runs on, and what the words mean.

## Mandate

| Pillar | What it covers |
|---|---|
| **Orders** | Order capture, validation and fulfilment flow (Easy Order) |
| **Training** | Rep enablement, webinars, certification (On24) |
| **Leading** | Territory and target setting, rep master data (Nexus, Dagster) |
| **Analysis** | Sales performance, KPIs, client-level reporting (Eagle Eye, Client reports) |
| **Control** | Compliance approvals for promo, speaker, event and sponsorship spend (DocPromo, MedCompli) |
| **Managing** | Day-to-day sales activity management in the CRM (ConnectPlus) |

## Conventions

- Anything decided goes in the wiki. Anything to be done goes on the board. Anything broken goes in an issue.
- Every app page states: purpose, owner, state, upstream, downstream.
