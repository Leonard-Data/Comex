# Glossary

| Term | Meaning |
|---|---|
| **ComEx** | Commercial Excellence — the Sales Forces team owning all sales operations |
| **CRM hub** | ConnectPlus, the system every sales activity flows through |
| **HCO** | Healthcare Organisation — sponsorship counterparty approved in MedCompli |
| **HCP** | Healthcare Professional — speaker/event fee counterparty |
| **Master data** | Rep, territory and customer reference data (Nexus + ComEx SQL Server) |
| **Territory mapping** | Assigning customers to reps; automated in Dagster |
| **SFA** | Sales Force Automation — the legacy platform being replaced |
| **AIS team** | External team owning Client reports |
| **Solution trace** | An issue documenting symptom → data path → root cause → fix |
| **CRM module** | One of the seven standard CRM functions in [CRM Modules](CRM-Modules.md); an app may own several |
| **Lead** | An unqualified contact captured by module 1, before scoring |
| **Opportunity** | A qualified lead with a stage and expected value, living in module 3 |
| **Dual-master** | Two systems holding the same entity with no agreed authority — currently Nexus and ComEx SQL Server |
